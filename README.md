## whoami

I'm a first-year Computer Science student at **Gurukula Kangri, Haridwar**, learning how software, networks, and security systems work under the hood.

I prefer understanding the mechanism over blindly running a tool. Most of my learning happens through small experiments, CTF practice, debugging, and documenting what I discover.

> **Current principle:** evidence before assumptions; permission before testing.

## current-focus

- **Foundations:** Python, C, Linux, Bash, networking, and Git
- **Security:** beginner CTFs, web fundamentals, cryptography, and defensive concepts
- **OSINT:** building **TraceLens**, a learning project centred on evidence-led, responsible investigation
- **Open source:** practising readable code, useful documentation, and careful debugging
